# Account Backgrounder — one-pager template

Built per interested role by the account-backgrounder run. Sources: company site, recent news, funding DBs, LinkedIn, the job posting itself. Cite links inline. Facts only — no adjectives without evidence. Max ~1 page. This document feeds the resume/cover letter builder and `qs` answers, so precision beats prose.

# <Company> — Backgrounder (for <role>, tracker id <id>)

## About Us
2–3 sentences: what the company does, who it serves, scale (customers/revenue/users where known).

## Mission
The company's stated mission, verbatim where possible, with source link.

## Vision
Stated vision or strategic direction (use investor letter / About page / CEO statements if no formal vision exists; note which).

## CEO
Name, short background (2 lines), tenure, one notable recent decision or statement.

## Relevant Links
- Careers/JD page (the actual posting URL)
- About page, newsroom/blog, LinkedIn company page
- Product pages relevant to the role

## Relevant Recent News (last 90 days, dated bullets)
- 3–5 items max, each with date + one-line relevance note (why it matters for this role/company trajectory).

## Funding & Status
Stage, total raised, last round (date/size/lead investor) or public/parent-company status; headcount estimate; hiring trajectory if visible. If a subsidiary/brand of a larger company, state the parent.

## Main Products
Bulleted list of the core products/lines with one-line descriptions. Flag which ones this role would touch.

## What You Would Be Working On
Derived from THIS job posting: responsibilities restated plainly, team/org placement if inferable, and 2–3 bullets mapping the candidate's specific proof points (from master-resume.md) to the stated responsibilities. Honest gap notes where a requirement exceeds his background.

## Watch-outs
Anything a candidate should know before applying: reviews red flags, controversial news, work-auth signals (sponsor history), level concerns.

## Application Tips (for this company + this role)
Concrete, evidence-based tactics to maximize interview odds — built from the JD, the company cache, and master-resume.md:
- **Resume keywords to include**: the 5–8 exact phrases this company's ATS/screeners will match (from the JD verbatim), plus which master-resume bullets already carry them.
- **Positioning strategy**: the ONE framing for the candidate against this role's mandate — which 2–3 proof points lead, how the pivot story is told for this company's context, which known gap gets pre-empted and how.
- **How they screen**: what this company/role's funnel prioritizes (referrals, early applicants, GPA/cert signals, work samples, cover letter expectations) — only claim what's evidenced (careers-page language, recruiter posts, reported processes).
- **Do / Don't for this application**: 2–3 each, specific to this company (e.g. name the product team's actual metric; don't open with generic praise).
This section is consumed by the resume builder and `qs` answers — write it as instructions, not commentary.
